What this V1 demonstrates

The standalone document combines edited AVP code, bounded execution, four fixed tutoring skills, relevant references, and hosted-model responses.

The teaching-method index uses local TF-IDF vectors over three draft method cards. MathDial informs probing questions. OATutor informs graduated hints. Algorithm notes provide coding facts.

This demo runner supports one function, integer values, read-only arrays, scalar assignments, while, if, return, comparisons, +, -, and length. It has execution limits. It does not verify the production AVP interpreter.

Later versions can add the production visualizer, semantic embeddings, reviewed learning measurements, local-model comparisons, and a self-scaffolding harness.
