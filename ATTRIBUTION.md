# Attribution

This project is a GitHub fork of [huytran088/avp_rag_system](https://github.com/huytran088/avp_rag_system), starting at commit `eaf18df`. The full Git history preserves the original authorship.

The upstream project supplies the AVP grammar and generated ANTLR files, AVP syntax reference, sample source files, ingestion/tracking logic, original API and frontend foundation, provider tests, and semantic code retrieval. The original retrieval implementation is retained as `semantic_retrieve.py`. The original README is archived at `docs/upstream-readme.md` for historical context, not current deployment instructions.

The fork adds execution-grounded tutoring, the reference visualization, teaching notes, dataset and evaluation tools, and reliability improvements. These additions do not imply ownership of the upstream language or contributions.
