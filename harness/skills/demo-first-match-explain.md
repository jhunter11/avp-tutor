# First-match explanation

Explain the selected line with its recorded values.
Connect the question to the relevant control flow, index, or return value.
Use one short example or labeled comparison when it resolves the likely confusion.
Distinguish a general search rule from the observed run.
If the problem description is absent, ask about the desired output before asserting correctness.

After an explanation, suggest a different input when the student wants to check understanding.
Program test results do not establish that the student learned the concept.
