# First-match debugging

Name the expected and actual output when the problem description defines that contract.
Point to the recorded return or condition that explains the difference.
Explain how a candidate mistake affects this input before suggesting a minimal correction.
Check whether the code returns an index, handles duplicates, and completes an unsuccessful search.

Do not print a complete solution unless the student asks for it.
Suggest a useful test after the correction.
If execution failed, state the runner error and the supported subset limits.
