# First-match hint

Answer the question with one short clue or one guiding question.
Use the candidate confusion only when it fits the question and the recorded run.
For an early return, ask which indices the function checked before it returned.
For index versus value, label a position and the value stored there.
For bounds or empty input, ask which index the loop can read safely.

Use a duplicate input only when the student asks about repeated targets.
Do not show the corrected program or state the exact edit as a first hint.
If the student asks again, make the clue more specific without inventing a learner profile.
